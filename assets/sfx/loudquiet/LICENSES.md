# Loud/quiet sound effects: sources and licenses

Real recordings used by Little Lanterns (Lantern Barn: "Loud or quiet?"). Eight loud/quiet pairs: lion / kitten, big drum / little bell, fire truck / bicycle bell, thunder / rain, cow / chick, trumpet / flute, dog / puppy, elephant / mouse. Every file comes from **Freesound**, and each author released it under **CC0 1.0 Universal (public domain dedication)**: https://creativecommons.org/publicdomain/zero/1.0/ . No attribution is required and commercial use is allowed; the authors are credited here anyway. No paid assets, no attribution-required licenses.

**Recorded vs synthesized:** all 16 sounds are real recordings (14 in this folder, plus the cow and the dog reused from `assets/sfx/animals/`). Nothing in this game is synthesized any more; `assets/js/sfx-animals.js` keeps its WebAudio drum only as a fallback when the big drum file can't load (and for the clapping game).

Processing (2026-10-30): downloaded the Freesound HQ preview of each CC0 sound, cut one sound (< 2 s), 90 Hz high-pass / 11 kHz low-pass, silence trim, -16 LUFS with a soft peak limiter, then mp3 (mono 24 kHz 64 kbps) + opus (32 kbps), same as the voice clips and the animal sounds. All files have the same loudness; the game makes a sound "quiet" by playing it at a lower gain (0.12-0.32) in WebAudio. Tools: /home/box/elearnea/voice/sfx/loudquiet/tools/. Machine-readable list with all measurements: `sfx.json` (this folder); the voice manifest lists them under `sfx` (ids `sfx.lq.*`).
